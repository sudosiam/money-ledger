# Duewell

A private, offline-first money ledger for tracking what you lend and borrow. It includes people and contact details, payment history, settings, backup/restore, and CSV import/export.

## Install on mobile

The GitHub Pages site will be available at https://sudosiam.github.io/money-ledger/ after the Pages deployment succeeds. On Android, open the link and choose Install app or Add to Home Screen. On iPhone, open it in Safari, tap Share, then Add to Home Screen.

If the first deployment does not start, open repository Settings → Pages and choose GitHub Actions as the build and deployment source.

## Your data

Balances and contacts stay in this browser on this device; they are not uploaded or synced. Use Settings → Download backup to move data between devices. Keep the backup private.

## App files

The installable app and its offline assets are in the site/ folder. GitHub Actions publishes that folder to GitHub Pages on pushes to main.
